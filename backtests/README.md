# Backtests

Where strategy ideas go before they earn the right to risk real (or even demo) capital.

## Process

For each strategy I want to test:

1. **Define rules clearly.** No "I'll know it when I see it." Every entry, exit, and SL rule must be objective enough that two people would mark the same trade.
2. **Pick a sample size.** Minimum 30 trades. 100 is better.
3. **Track every trade in a spreadsheet** (or generated by code later).
4. **Compute the stats:**
   - Win rate
   - Average R win / loss
   - Expectancy (per trade)
   - Max drawdown (in R)
   - Longest losing streak
5. **Decide.** Profitable expectancy + I can stomach the drawdown → forward-test on demo. Otherwise → drop or refine.

## Expectancy formula

```
Expectancy (R) = (Win% × Avg Win in R) − (Loss% × Avg Loss in R)
```

Anything > 0.2R per trade is workable. > 0.5R is great.
