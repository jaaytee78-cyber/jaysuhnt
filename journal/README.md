# Journal

The journal is the edge. Win or lose — every trade gets logged.

## Structure

- `trades/` — one markdown file per trade, named `YYYY-MM-DD-<instrument>-<#>.md`
- `weekly-reviews/` — every Sunday, a review of the week
- `psychology.md` — recurring patterns I notice in my own behavior

## Trade log template

Copy `_template.md` for each new trade.

## What I track per trade

- Setup (which strategy / playbook entry)
- Bias (and where it came from — HTF structure, etc.)
- Entry trigger
- Stop loss & target (in pips/points and in R)
- Result (in R, not just $)
- Screenshot links (TradingView idea share)
- What I did well
- What I did poorly
- One thing to remember
